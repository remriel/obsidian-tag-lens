# Tag Lens 
 
Tag Lens opens a reading modal when you click an inline tag in an Obsidian note. It groups matches from across the vault alphabetically by note path and links to their sources. 
 
## Install locally 
 
1. Create a folder named `tag-lens` inside the vault's `.obsidian/plugins/` folder. 
2. Copy `manifest.json`, `main.js`, and `styles.css` into that folder. 
3. Reload Obsidian and enable Tag Lens under Settings > Community plugins. Tag Lens has not been submitted to the Obsidian community directory. 
 
To build and verify from source, run `npm install`, `npm run build`, and `npm test` in the project directory. The included `main.js` was generated by esbuild from `main.ts`. See [SUMMARY.md](SUMMARY.md) for verification status. 
 
## Read a tag 
 
Click a tag in Reading view or on a rendered tag in the editor. Click a result's path and line number to open its source. 
 
- **Tag Lens: Read tag under cursor** opens results for the tag under the editor cursor. It prompts for a tag when the cursor is elsewhere. 
- **Tag Lens: Read a tag...** prompts for a tag. A leading hash is optional. 
 
**Whole-section reading** is on by default and is saved in plugin settings. Each result shows the heading and complete section as plain text. A section starts at an ATX Markdown heading (one to six hash marks) and ends before the next heading of the same or higher rank, or at the end of the note. Deeper headings and their text stay inside the parent section. A tag found only under a deeper heading returns that nested section. Content before the first heading appears as `(no heading)` when it matches. The source link points to the first tagged line in the displayed section, including the heading if it contains the tag. 
 
Turn **Whole-section reading** off to fall back to paragraph mode. Blank lines separate paragraphs, ATX headings get their own blocks, and contiguous list items stay together. Paragraph links point to the start of the paragraph. 
 
Matching ignores case, frontmatter, and fenced code. Fenced code stays visible in the full section, and heading-like lines inside fences never start a section. Searching `#project` includes descendants such as `#project/ideas`. Searching `#project/ideas` requires that exact tag. 
 
**Maximum results per tag** defaults to 200 sections or paragraphs across all notes. Tag Lens stops reading files when it reaches the cap. The modal reports unreadable files encountered during the search.

## Privacy 
 
Tag Lens is local-only and read-only. It never modifies your notes and makes no network calls. It uses no LLM, account, or API key. Settings are saved locally by Obsidian.
